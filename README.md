# 🎯 Breast Cancer Classification with Machine Learning

Español:

📋 Proyecto Descripción: 

Este proyecto implementa un clasificador de cáncer de mama de alto rendimiento utilizando múltiples algoritmos de Machine Learning, aplicando metodologías rigurosas de análisis de datos y evaluación de modelos. El proyecto surge del primer módulo del curso intensivo de ML & AI para analistas de la Bourbaki School of Mathematics, enfocándose en la profundidad matemática y la comprensión profunda de los algoritmos.

🔍 Enfoque del Proyecto
Análisis Exploratorio Completo: Visualizaciones interactivas y técnicas avanzadas de análisis de datos
Comparación de Modelos: Evaluación rigurosa de múltiples algoritmos de clasificación
Rigor Matemático: Enfoque profundo en fundamentos teóricos y modelado matemático

English:

Play of multiple models and algorithms to make a breastcancer classifier. We explore data with different nice visualization tecniques and then proceed to a rigurous analysis
using Machine learning algoritms. 

I tried to use all the knowdledge learned in the first module of an intensive ML&AI course for the working analyst held by Bourbaki school of mathematics. The program is more than bootcamp because it goes far more deep in the mathematical models study, problematization of the case-uses and understanding of the model and algorithms.

That is why this repo might interest the visitors who wish to see an integral implementation of decision tree and random forest classifier for my problem solving. Along that we use perceptron, SVM as well as an approach with logistic regression and Ridge for the classification to contrast the performances and conduct a practice in evaluation of the algorithms.
